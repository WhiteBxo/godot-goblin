# 地图美术与素材处理

适用于地图原图、图集、分层裁片与地图素材生成；关卡引用这些素材时同样遵守本规范。

- 常规地图线条基准为 `assets/map/settlement/source/style_milk_tea.png`：清晰近黑描边、阶梯像素边缘、有限平涂与克制阴影。区域装修服从自身用途，不能把酒馆、军营等都装修成奶茶店。
- 洞窟聚落是一整片大洞窟内的连续平地，外围岩壁围合整张地图；用人造建筑或开放功能区组织场景，不把各区域画成独立小洞穴或悬空地台。整图建筑必须表现外墙厚度与外侧。
- 以约 110 世界像素高的主角校准门口、家具与步行距离；保持场景素材原始比例。尺寸或布局不合适时调用 imagegen 重新生成，不拉伸整张素材补救。
- 地面可按原尺寸裁片平铺，遮挡可提取局部裁片，相机可以统一缩放；这些操作不能改变素材宽高比，也不能改整图透明度冒充局部遮挡。
- 源图、提示词与派生素材分开保存，记录来源和可复现步骤；沿用 `source/`、`prompts/` 等既有分类，不依赖导出中排除的源文件运行游戏。
- 奶茶店背景与前景分层见 [裁片说明](milk_tea_layers/README.md)；模块化素材见 [素材库](../../docs/assets/modular_assets/README.md)。修改工具读 [工具规范](../../tools/AGENTS.md)。
- 地图素材不定义通行规则。更新图像后按 [关卡规范](../../src/levels/AGENTS.md) 核对碰撞、步行空间、锚点和遮挡，只修改本次直接相关的关卡配置。

验收给出素材来源、处理方式与实际关卡观察结果；生成图或静态预览不能替代游戏内比例、通行和遮挡验收。
