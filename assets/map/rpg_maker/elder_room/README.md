# Elder Room Pixel Assets

These transparent PNG map props were generated from the 18 Chinese prompts in the source PDF:

`C:/Users/TempAdmin/Documents/xwechat_files/wxid_6t0wvn0sazuz22_5957/msg/file/2026-10/长老房间prompt（18个）.pdf`

The files use exact RPG Maker tile footprints from the prompts. They are rendered as crisp, nearest-neighbor pixel art with no antialiasing and are intended for map placement, not as full-scene backgrounds.

The generated images are derived assets. The source PDF remains outside the repository and is not copied into the project.

The pixel drawings can be regenerated with `python _generate_elder_room.py` from this directory. The generator keeps the requested RPG Maker footprints, RGBA transparency, nearest-neighbor edges, and the shared elder-room palette.
