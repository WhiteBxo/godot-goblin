# Day 1 精简版剧情冒险：开发执行规格（Godot 2D）

> **文档状态**：Game Jam 最小可玩版本（MVP）实施稿  
> **文档目标**：将三份策划/文案材料中**第一天必需的内容**转换为可以拆任务、实现、验收的开发要求。  
> **核心原则**：**剧情优先，固定流程，少量交互；不再为了表现哥布林社会而制作完整社会模拟。**  
> **目标成品**：玩家可以独立完成一段有开场、目标、冒险、反转、结尾的短篇，建议目标时长 **15–20 分钟**（估算，并非原文要求）。

## 0. 本文约定：哪些来自原稿，哪些是实施取舍

- **【原稿】**：三份来源文档中明确出现的剧情或系统意图。
- **【MVP决定】**：考虑“砍掉复杂系统，只留剧情”的项目方向，为保证可交付而做的简化。它**不是原稿已经批准的规则**。
- **【待确认】**：来源有冲突、缺少关键数据，需文案/负责人一次性拍板。不得由程序自行无限补设定。

**设计冻结原则**：在本版本中，所有功能必须直接服务于下面六个剧情阶段。新功能若无法改善这一段可玩流程，就不进入 Day 1 MVP。

## 1. 游戏定位与完成标准

### 1.1 产品定位

- 类型：**2D 俯视角、线性剧情冒险、轻量探索与交互**。【MVP决定；俯视角来自当前项目技术方向】
- 体验重点：荒诞喜剧、异世界反差、角色对话、简单互动、结尾反转。
- 玩家操作：**移动、交互、查看当前目标、完成简化奶茶制作**。极少量引导式躲避或道具互动可选。
- 不强调：重复游玩、自由经济、自由潜行、沙盒式 NPC 生态、多结局、复杂战斗。

### 1.2 Day 1 视为“可通关”需同时满足

1. 能从新游戏开始，按顺序体验六个剧情阶段，直至结尾画面。
2. 核心剧情不需要开发者打开编辑器或手动改变量推进。
3. 玩家能理解当前目标，并通过场景交互亲自触发关键进展。
4. 所有关键事件仅触发一次；离开/返回场景不会导致重复领奖、重复对白或断档。
5. 不会因金币、道具使用、守卫、错误路线而出现无法继续的死局。
6. 最后必须表现“胖哥布林饮用格里芬之血特调后发生异常”，并留下关于“格里芬之血”的疑问。

### 1.3 不做什么（明确禁止进入 MVP）

| 原稿系统 / 想法 | Day 1 处理方式 |
|---|---|
| 哥布林社会模拟、职级关系、NPC 自主经济 | **删除实现**；仅通过台词/演出表达 |
| 普通委托刷新、评级、金币奖励平衡 | **删除**；仅保留一条剧情委托 |
| 通用贿赂系统、多种可委托 NPC 行为 | **删除**；醉酒守卫贿赂改为一次脚本事件 |
| 战斗、血量、敌人攻击、追击脱战 | **删除**；如需紧张感，仅用短演出/触发区 |
| 复杂卫兵 AI（视野/听觉/群体警报） | **删除**；不做状态机生态 |
| 火焰传播、区域混乱值、纵火毁建筑 | **删除**；可用一次剧情烟雾/失火演出代替，但非必需 |
| 大量可投掷物和投掷属性 | **删除**；投掷硬币引开守卫仅列为 P1 |
| 奶茶战斗属性、异常状态、复合效果 | **删除** |
| 食材五级稀有度、随机掉落、采购/雇佣采集 | **删除** |
| AI 动态生成饮品、爆品配方、自动数值结算 | **删除** |
| 完整背包、配方图鉴、经营数据统计 | **删除**；剧情道具通过标志位维护 |
| 开放式探索地图、大型地下聚落 | **删除**；只搭建服务剧情的一条小路线 |
| 七日全部剧情和多结局 | **本轮不做**；只实现 Day 1，并留下 Day 2 伏笔 |

> 判定标准：如果某机制**只在 Day 1 被使用一次**，优先用一次剧情脚本实现，禁止先做“以后也许用得上”的通用框架。

## 2. 玩家实际体验：六段流程

| ID | 阶段 | 地点 | 玩家亲自做什么 | 关键演出与结果 | 完成判定 |
|---|---|---|---|---|---|
| S01 | 穷困潦倒的奶茶店老板 | 奶茶店 | 接单，选择茶底、奶精、小料，交付 | 建立破产老板与普通世界的处境 | 第一杯奶茶交付成功 |
| S02 | 奇怪的金币 | 奶茶店 | 与哥布林顾客互动，完成一笔指定订单 | 哥布林用奇怪的金币付款；提到赌场、长老、格里芬之血 | 金币到手、异常对话结束 |
| S03 | 消失的街道 | 店外 / 洞窟入口 | 从店门出去，在极小范围走动并查看环境 | 原本街道变为哥布林聚落；主角震惊 | 触发几个必要的观察点或返回门口 |
| S04 | 格里芬的赏赐 | 店外 | 与胖哥布林对话，获得委托信息 | 介绍格里芬信仰和长老；提出取得格里芬之血的委托 | 对话完成，任务目标更新 |
| S05 | 夜间潜入 | 洞窟小关卡 / 长老居所 | 沿路线前进，触发守卫对话，调查文书，拾取格里芬之血，返回 | 醉酒守卫索贿并提出次日特殊奶茶订单；发现“黄金乡”“变量” | 持有格里芬之血并回到出口 |
| S06 | 第一杯格里芬之血特调 | 奶茶店 | 制作特调，交付给胖哥布林，查看/帮助他 | 胖哥布林口吐白沫、倒下；主角怀疑圣物 | 结尾对白播放完毕，出现“第一天结束” |

**剧情主线不得因技术简化而删除的要素**：破产奶茶店、哥布林金币、街道变成异世界、胖哥布林的委托、长老与格里芬之血、醉酒守卫的特殊奶茶订单、古文书上的“黄金乡/变量”、胖哥布林的异常反应。

### S01 — 普通奶茶制作教学

- **进入条件**：新游戏开始。
- **场景**：奶茶店；柜台、订单位置、制作台、交付位置。
- **交互顺序**：与订单/顾客互动 → 根据固定订单选择**茶底、奶精、小料** → 点击制作 → 交付顾客。
- **成功反馈**：制作完成提示；顾客台词/离场；任务推进。
- **【MVP决定】**：只支持**一个固定订单**，材料可无限供给，不扣库存，不做口味评价和找零经济。错误选择可撤销或提示正确材料，不能卡关。
- **验收**：从进入场景到交付完成，不超过几次直观交互；玩家知道下一步去哪里。

### S02 — 哥布林与奇怪的金币

- **进入条件**：`tea_intro_completed = true`。
- **演出**：第一名哥布林进店购买奶茶，用陌生金币支付；后续哥布林顾客闲聊“赌场、长老、格里芬之血”等关键词。
- **操作**：可复用 S01 的制作界面完成一个固定订单；随后通过对话继续剧情。
- **状态**：`weird_coin_obtained = true`；玩家获知金币异常。
- **【MVP决定】**：多名顾客可用背景立绘与对话呈现，**不要求每位 NPC 都有自主排队/购物 AI**。
- **完成**：主角决定到外面查看情况，店门成为下一目标。

### S03 — 街道消失

- **进入条件**：玩家从奶茶店出口交互。
- **场景切换**：使用现有场景切换方案，加载紧凑的洞窟入口/街道环境（顶视 2D）。
- **交互**：至少一个可调查点，例如金币或摊位；远路可以通过主角台词提示“先别走太远”。
- **【MVP决定】**：只用**一个小型活动区域**表现异世界，远景不需可到达，不创建整座城市。
- **完成**：触发主角意识到“店铺连接了异世界”的对白，胖哥布林登场。

### S04 — 胖哥布林的委托

- **进入条件**：`otherworld_discovered = true`。
- **演出/对话要点**：
  1. 胖哥布林自来熟，认为主角可能是格里芬派来的行脚商。
  2. 说明哥布林信仰格里芬、长老拥有权威。
  3. 介绍“格里芬之血”被宣传为珍贵圣物，真实作用仍未知。
  4. 透露长老今晚不在居所，希望主角替他取来格里芬之血。
  5. 主角因为需要赚钱而接受委托。
- **操作**：与胖哥布林互动、推进对白；弹出当前目标“前往长老居所取得格里芬之血”。
- **【MVP决定】**：取消“接受/拒绝但都会接受”的伪分支，改为剧情对白直接承接；如已写好不同台词，可将其作为**纯对白风味选项**，不影响状态。
- **【MVP决定】**：胖哥布林给出地图的情节保留，但地图可用一张**静态示意图或目标方向标记**替代完整小地图寻路系统。
- **完成**：对话结束且 `quest_blood_active = true`，允许进入夜间小关卡。

### S05 — 夜间潜入（唯一需要简单关卡设计的段落）

- **进入条件**：委托已激活；通过门/事件切入夜间。
- **最小关卡结构**：

  ```text
  入口（安全起点）
      │
      ▼
  简短洞窟通路（环境提示/极简遮蔽物）
      │
      ▼
  醉酒守卫剧情触发点（强制出现）
      │
      ▼
  长老居所（神秘文书 + 格里芬之血）
      │
      ▼
  返回入口 → 奶茶店
  ```

- **必需交互**：
  - 靠近醉酒守卫 → 触发对话：误认主角为行脚商、索要金币、放行。
  - 守卫还提出**第二天傍晚特殊奶茶订单**，原料与赌场/酒馆有关（只登记伏笔，**不创建 Day 2 任务地图**）。
  - 进入长老房间后，调查**神秘文书**，显示“黄金乡”“变量”两个词，不揭秘全文。
  - 拾取**格里芬之血** → 目标变为“返回奶茶店”。
  - 从入口离开，返回店内。
- **【MVP决定】**：守卫贿赂是**专用对白事件**。金币可显示扣除 1 枚（仅作为实现建议；具体金额原文未定），正常流程保证剧情前玩家已持有足够金币；调试中的异常余额也需有兜底对白直接放行。无通用贿赂 UI、NPC 雇佣和谈判树。
- **【MVP决定】**：**不做通用潜行 AI 与战斗**。可用短暂固定巡逻路线、视线区域或剧情镜头营造紧张感；即使被发现，也必须可原地重试或被送回安全起点，不能死亡/失败锁死。
- **【MVP决定】**：探索文档中的**双守卫投掷 + 贿赂教程、放火制造群体混乱撤离**不纳入主线必需条件，见第 7 节冲突表。
- **先后约束**：神秘文书必须先被调查，再允许取得格里芬之血，以保证“黄金乡/变量”伏笔不会被跳过。
- **完成**：`has_griffin_blood = true` 且玩家完成返店事件。

### S06 — 格里芬之血特调与结尾

- **进入条件**：从地下回到奶茶店、持有格里芬之血。
- **操作顺序**：进入制作界面 → 选择格里芬之血作为特殊原料 → 选择用量/确认制作 → 交付给胖哥布林 → 观看异常演出 → 与他互动确认状况。
- **演出关键帧**：喝下特调 → 身体抽搐 → 口吐白沫/晕倒 → 主角震惊 → 胖哥布林质疑长老说法。
- **【MVP决定】**：材料用量可以做成 **少/中/多 3 档**，但**三种选择统一进入既有中毒剧情**；不做药效模拟、不加隐藏数值。若文案提供 3 段短台词，可仅差异化角色吐槽。
- **剧情认知**：玩家只知道“格里芬之血可能有危险”，**不能提前揭露**其真实毒性与长老阴谋。
- **完成**：`day1_completed = true` → 出现“第一天结束 / 未完待续”，可回标题。

## 3. 最小功能清单与优先级

### P0 — 缺一不可，优先做完一条完整通关路径

| 模块 | 必须实现的最小能力 | 验收方式 |
|---|---|---|
| 玩家角色 | 2D 四向移动，场景内不可穿越墙体 | 能从店内走到可交互点、在洞窟行走 |
| 交互 | 接近对象显示提示；按交互键触发一次行为 | NPC、门、文书、物品、制作台统一可交互 |
| 对话 | 文本逐句、角色名称/立绘（有则展示）、关闭/继续 | 对话不串句，结束后可触发指定事件 |
| 剧情控制 | 线性阶段状态与事件一次性触发 | S01→S06 可连贯完成、不重复触发 |
| 场景切换 | 奶茶店 ↔ 洞窟入口 ↔ 长老居所（可合并） | 出入口正确，玩家落在预设位置 |
| 简化奶茶制作 | 固定订单选择原料并提交；结尾特殊原料加入 | 两次必要的制作剧情均能完成 |
| 剧情物品 | 奇怪金币、神秘文书（已读标志）、格里芬之血 | 拾取/阅读后正确推进目标 |
| 当前任务 | 屏幕简短显示“下一步做什么” | 任何阶段不需猜测目的地 |
| 角色与关键演出 | 胖哥布林、哥布林顾客、醉酒守卫及结尾异常 | 无需高复杂动画也能看懂剧情 |
| 结尾 | Day 1 完结与回到标题 | 无法误触继续进入未开发内容 |

### P1 — P0 完整可玩后再考虑

| 功能 | 最小版本 | 不做的延伸 |
|---|---|---|
| 引导式潜行 | 一名守卫、一段短巡逻、有限重试 | 复杂感知、多人追击、全局警报 |
| 投掷金币 | 固定落点或简单瞄准一次，把守卫引开 | 通用物理抛射与所有投掷物 |
| 见闻录 | 4–6 条**固定文字**随剧情解锁/更新 | 全百科、搜索、自动推理、复杂分类 |
| 小地图 | 固定地图贴图 + 当前位置/目标标记 | 导航寻路、地图探索迷雾 |
| 反馈演出 | 表情、气泡、音效、镜头震动、音量变化 | 全套骨骼动画或高成本过场 |
| 检查点 | 地下入口一处恢复点 | 多档存档和完整存档 UI |

### P2 — 明确延后

所有 Day 2 及以后剧情内容、普通委托、数值平衡、经营模拟、声望/派系关系、NPC 自主行为、战斗、特调奶茶武器化、真实燃烧传播等。

**执行顺序**：先打通“剧情占位文字 + 方块场景”的 P0，再填对话、立绘、音效。绝不先制作 P1/P2。

## 4. Godot 4.x 最小实现建议（不绑定具体仓库结构）

> 以下是面向当前 **Godot 俯视 2D** 项目的轻量工程建议，属于【MVP决定】，不是原稿已有的技术方案。若项目已存在同等能力，**直接复用**，不要重建架构。

### 4.1 建议的场景职责

```text
Main.tscn                  # 总入口（可复用现有主场景）
├── Player                 # 玩家移动与碰撞
├── SceneRoot              # 加载当前场景内容
└── UI                     # 对话、任务提示、简单交互提示

Scenes/
├── MilkTeaShop.tscn       # 奶茶店；S01、S02、S06 复用
├── CaveEntrance.tscn      # 店外/洞窟入口；S03、S04
└── ElderRoute.tscn        # 小型潜入路线 + 长老房间；S05

Autoload/
└── GameState.gd           # 最小剧情状态 / 场景入口信息

Systems/
├── StoryDirector.gd       # 根据事件推进阶段
├── Interactable.gd        # 可交互对象公共入口
├── DialogueUI.gd          # 对话展示
└── TeaMakingUI.gd         # 两处必要制作事件
```

- **只有 3 张左右地图**，长老居所可直接做在 `ElderRoute.tscn` 内，不必单独切图。
- 玩家、UI、对白、场景切换**优先复用**项目中已有实现，文件名仅是职责示意。
- NPC **不需要通用行为树**：关键角色只需“待机/触发对白/离场或切换表现”。

### 4.2 剧情数据（最小状态集合）

```gdscript
# 示例字段：可实现为 Dictionary / Resource / 普通变量，不要求全部照搬命名
var story_stage: StringName = &"S01"
var flags := {
    "tea_intro_completed": false,
    "weird_coin_obtained": false,
    "otherworld_discovered": false,
    "fat_goblin_met": false,
    "quest_blood_active": false,
    "drunk_guard_event_done": false,
    "ancient_document_read": false,
    "has_griffin_blood": false,
    "blood_tea_made": false,
    "day1_completed": false,
}
var gold: int = 0                 # 仅为故事演出/守卫索贿，非完整经济系统
var blood_amount: int = 0         # 0 未选择；1/2/3 仅用于末尾对话展示
```

**约束：**

- `story_stage` 是唯一主流程进度来源。交互事件必须检查当前阶段与先决条件。
- 一次性事件通过 `flags` 防重复；重复交互应播放已完成提示或正常对白，**不得再发放物品**。
- 剧情道具不需要通用库存槽位；物品资源可以使用 `item_id` 与布尔标志驱动。
- 若已有持久化系统可存这些字段；没有的话，P0 **不要求开发完整存档**，但必须支持重开/返回标题。

### 4.3 最小事件 API（职责约定）

- `try_interact(target_id)`：检测目标是否可以在当前阶段使用；仅将事件交给剧情控制器。
- `start_dialogue(dialogue_id)`：打开对白 UI；完成时发出 `dialogue_finished(dialogue_id)`。
- `set_objective(text)`：更新屏幕的一行目标提示。
- `set_flag(flag_name, value)`：改状态，必要时刷新 UI/场景。
- `go_to_scene(scene_id, spawn_id)`：切换场景并指定出生点。
- `advance_stage(next_stage)`：确认完成条件后推进；开发模式记录日志。

> 不需要为了这些 API 创建事件总线、任务树、条件编辑器、数据库等复杂设施。优先明确、可调试。

## 7. 三份原始文档的冲突与统一决定

| 项目 | 剧情稿 / 另一份系统稿 | 探索系统稿 | 当前 MVP 统一方案 |
|---|---|---|---|
| 玩家任务目的 | 胖哥布林明确要求取得“格里芬之血” | 委托面板核心目标写 `???`，强调不剧透 | **采用剧情稿**：玩家明确知道要找格里芬之血；古文书、圣物真实用途未知 |
| 守卫桥段 | 必定遇见一名醉酒守卫；贿赂后预订次日奶茶 | 长老房间外两卫兵，要求投掷金币 + 贿赂 | **采用剧情稿**：醉酒守卫必需；双守卫组合教学不做 P0 |
| 潜行难度 | 避开巡逻、被发现可逃离或重试；Day 1 无死亡惩罚 | 发现玩家进入战斗、脱战、警报、区域混乱 | **剧情化小关卡**：不做战斗；最多做一处低成本躲避演出 |
| 撤离流程 | 拿到圣物后原路返回 | 投掷火把制造群体混乱才能撤离 | **采用剧情稿**：原路返回；纵火演出不做 P0 |
| 奶茶功能 | 基础奶茶教学、结尾格里芬之血特调 | 特调奶茶可投掷、战斗属性复杂 | **只保留剧情制作**，不武器化 |
| 地图 | 胖哥布林提供洞穴地图；探索有区域限制 | 任务小地图黄点 + 任务评级 | 保留“获得地图”的叙事，界面仅保留目标提示；可选静态地图 |
| 见闻录 | 随事件更新重要人物、圣物与疑问 | 搜索文书同步见闻录 | P0 用剧情对白保证玩家获得信息；P1 才做可浏览的精简见闻录 |
| 时间标注 | 文案六阶段归为 Day 1，但第二阶段屏幕写“第二天” | 按 Day 1 地下流程排列 | **待确认文案**：建议 Day 1 作为“可玩章节”，不要额外实现多日调度；显示何种日期需统一 |
| 金币结算 | 哥布林消费获得金币，守卫索贿 | 不同 NPC 贿赂价格/经济平衡 | 只保留一个固定剧情金币数字，不做经济循环 |

### 必须由内容负责人一次性确认的 3 项

1. **日期文案**：S02 是否仍显示“第二天”？若保留，Day 1 代表“第一章节”而非日历第一天；若不保留，请文案给出准确时间标签。
2. **醉酒守卫对白及支付金额**：沿用剧情稿台词；金币具体扣除多少枚需明确。默认技术实现可设为 1 枚且确保余额充足。
3. **格里芬之血用量反馈**：是否要求不同用量对应不同台词？若没有文案，不影响剧情，统一结尾表现。

**这些确认项都不能阻止程序先做事件占位版本。** 先使用默认占位值实现一遍完整流程，收到最终文案后替换数据即可。

## 8. 建议开发顺序（以可玩闭环为目标）

### 里程碑 M1：完全打通流程（最高优先级）

- [ ] 创建/复用三张场景；玩家能从奶茶店去洞窟再回店。
- [ ] 放置必要的交互对象与剧情触发区。
- [ ] 对话 UI 可播放占位文字，并在结束时触发事件。
- [ ] 以 `story_stage` 串联 E01–E15，全程无需开发者作弊跳关。
- [ ] 做出结尾最简占位演出。

**完成定义**：没有正式画风也能从开始玩到结尾。

### 里程碑 M2：补齐体验必需互动

- [ ] 固定订单奶茶制作与交付。
- [ ] 哥布林金币、格里芬之血、古文书等剧情交互。
- [ ] 当前目标提示与阶段推进提示。
- [ ] 醉酒守卫贿赂对白及次日订单伏笔。
- [ ] 所有剧情事件防重复、错误操作不锁关。

**完成定义**：试玩者不用作者口头指挥即可完成。

### 里程碑 M3：补演出，不扩系统

- [ ] 用正式台词替换占位文本。
- [ ] 添加角色立绘/表情/场景氛围。
- [ ] 突出三次情绪转折：首次哥布林出现、店外变异、胖哥布林中毒。
- [ ] 添加必要音效、镜头/淡入淡出、结束提示。
- [ ] 邀请非开发成员完整试玩，并记录卡点。

**完成定义**：短篇故事节奏完整，关键情绪能够传达。

### 只有 M1–M3 全部完成，才允许进入 P1

不允许在尚未通关的情况下提前开发复杂潜行、任务刷新、AI 配方、动态贿赂等系统。

## 9. 验收测试（交付前必须实际跑）

| 测试 | 操作 | 预期 |
|---|---|---|
| 正常流程 | 新游戏按目标依次互动至结束 | 可一次通关，无硬阻塞 |
| 重复互动 | 连续点击/按键与已完成 NPC、文书、物品交互 | 不重复发放物品、不重复推进主剧情 |
| 剧情跳序 | 提前跑到出口/长老房间或返回店铺 | 不跳过必要剧情，当前目标正确 |
| 错误奶茶原料 | 故意选错或不选原料 | 可返回修改，不崩溃/卡住 |
| 金币不足 | 在调试中将金币设 0 后触发守卫 | 出现可继续的兜底，不造成死局 |
| 快速按键 | 对话连续快速确认、频繁交互 | 无双触发、无残留对话框 |
| 切换场景 | 进出奶茶店 / 洞窟 | 出生点正确，关键标志不丢失 |
| 取得圣物 | 拿到格里芬之血后检查目标 | 目标从“取得圣物”变为“返回奶茶店” |
| 文书悬念 | 查看文书和最后的剧情记录 | 只出现“黄金乡/变量”与疑问，不暴露真相 |
| 结尾事件 | 交付特调，照看胖哥布林 | 中毒演出只播放一次并结束章节 |
| 画面适配 | 测试目标游戏窗口比例 | UI 文字、交互提示不遮挡关键内容 |

**验收标准**：至少一次由**没有参与开发的人**完整试玩，记录开始时间、结束时间、任何卡关点和不理解的目标。P0 必须解决卡关；非关键美术问题可延后。
