# 后续流程 BGM 缺口与生成提示词

当前正式 BGM 只有 `music.daily_milk_tea`（店内日常）和标题页 `start.ogg`。第一晚潜入、聚落白天、异常揭示与第二天各场景没有音乐，只有 `ambience.cave` 环境声。本文件记录缺口、可直接交给 AI 音乐工具的提示词，以及素材到位后的接线位置；不把尚未制作的文件写成已接入。

## 可直接使用的提示词

1. **聚落白天**：清晨的哥布林聚落市集，温暖而带异乡感；轻世界民谣；木质拨弦（鲁特琴、曼陀林）、手鼓、低音木管（大管）、偶发口哨与远处叫卖；96 BPM，4/4，明亮大调中间夹一次小调转折；60–90 秒无缝循环，前 4 秒淡入主动机，中段留空给环境声；不要强烈打击乐，避免盖住脚步与对白。
2. **夜间潜入**：夜间潜入长老居所的克制的紧张感；暗色氛围与极简悬疑；低音弦乐持续音、心跳式定音鼓、稀疏金属泛音与反向混响；58–66 BPM 或自由拍；60–90 秒循环，不出现强旋律，第 8 秒后才加入脉冲低音；结尾必须能无缝接回开头。
3. **异常揭示**：发现异常时的悬疑与不安，轻微失真；低频持续压迫音、玻璃摩擦泛音、倒放钢琴单音，偶发极短静默；自由拍；40–60 秒循环，最后留 1 秒空白便于接入撞击音效；不要鼓点推进，保持“不对”的空洞感。
4. **夜谈与委托**：胖哥布林委托与夜谈的信任与乡愁；室内乐加一点轻爵士；钢琴、木吉他、手风琴、轻刷鼓；72–80 BPM，大调带蓝调音；70–90 秒循环，旋律简单可重复；音量偏小，像背景里的旧收音机。
5. **群客入场（可选）**：三名哥布林一起进店的滑稽又带压迫的短过场；8–12 秒可无缝循环；大管、低音铜管、拨弦、木鱼；110 BPM；一段动机重复两遍即可，不要完整旋律。

## 素材到位后的接线

1. 将 Ogg 放到 `assets/audio/music/`，保持文件名稳定；不要让测试或文档引用尚未提交的文件。
2. 在 `src/resources/audio/sound_library.tres` 增加 `ext_resource` 与 `entries` 行：`loop = true`，`loop_offset` 按实际循环点填写；`AudioManager` 只接受 Ogg 循环。
3. 在对应剧情事件或场景控制器里增加 `play_bgm`；第一晚进入聚落时可先用现有 `fade_bgm` 压低环境声，再起播新曲。
4. 运行 `tests/verify_sound_library.gd` 与受影响的剧情宿主检查；新增 ID 未实际播放前，不要写成已经解决 BGM 缺失。
