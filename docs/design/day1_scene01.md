# day1_scene01

- 宿主场景：独立奶茶店试编排场景 `src/debug/story/day1_scene01_demo.tscn`。
- 启动方式：F6 运行试玩场景，进入奶茶店后自动开始。
- 播放次数：只播放一次；同一运行进程内以 GameState 完成记录防止重复播放。重新 F6 可重新试玩。
- 剧情范围：介绍主角被快招公司诈骗、负债经营的背景，演到第一位顾客点单为止。本次不编排制作教学、玩家交付或后续场景。

## Beat background

- 执行模式：自动演出
- 前置条件：无
- 角色：玩家
- 位置：在柜台后面
- 演出：玩家面向柜台外。
- 对白：玩家说：「我是一个没什么本事、手头拮据的普通人，」
玩家说：「被快招公司坑了之后背上债务，开了一家生意惨淡的奶茶店。」
玩家说：「我想赚钱买房买车、孝敬父母、解决人生大事，」
玩家说：「但眼下最现实的目标就是别让店倒闭。」
玩家说：「店里已经连续几天没什么客人啊。」
- 验收：独白结束，保持自动演出，停顿两秒后进入顾客到店段。

## Beat customer_arrives

- 执行模式：自动演出
- 前置条件：background 独白完成后两秒
- 角色：顾客 customer；本次试编排复用现有暖色调试占位角色，不代表正式人类顾客美术。
- 位置：从门口 door 出发，经门内过道 aisle，走到现有订单板 orders（本稿所称订单机）前方的 counter。
- 演出：
  1. 播放门铃，等待音效结束。
  2. 主角面向门口，镜头用 0.9 秒聚焦门口。
  3. 顾客在门口出现；同时让镜头跟踪顾客，并让顾客沿过道走到订单机面前。
  4. 顾客到达后面向柜台后的玩家。
- 对白：顾客说：「你好，我要一杯普通奶茶。」
- 收尾：镜头恢复正常跟随，标记本次剧情完成，玩家重新获得移动和交互控制权。
- 验收：顾客停在柜台外，不消失；玩家能正常移动和交互；同一进程内不自动重复播放。

## 编排约定

- 本次两段为一个连续自动演出事件 `day1.scene01`，中间两秒也保持输入锁；不包含玩家操作 Beat 或 Gameplay Bridge。
- 保留六句原文对白，不增加教学、顾客反应或配方定义。“普通奶茶”只作对白，不绑定业务订单。
- 试玩宿主独立组装现有 `src/core/main.tscn`；不改默认聚落入口，不接入正式进店触发。
- 玩家使用现有柜台后出生点，地图局部坐标 (956, 365.6)，朝下；门口在右下方，主角转向下。
- Marker 保存于试玩场景，坐标为地图局部坐标，注册前同步地图 global_transform（当前含 1.25 倍缩放）：door (1123, 710)、aisle (1123, 550)、counter (844, 550)。顾客到达后朝上；这条折线路径绕开柜台及候客区家具。
- 顾客由 `actor_spawn` 实例化 `res://src/debug/cinematic/customer.tscn` 并注册为 customer；步行速度 120 世界像素/秒，各段 timeout 8 秒。
- 门铃复用 `res://assets/audio/shop/door_bell.wav`，注册为 `shop.door_bell`，等待自然播放结束；本次不新增 BGM。
- 镜头聚焦门口用 0.9 秒，切换到顾客跟踪用默认 0.8 秒并与步行并行。
- 取消演出不记录完成；取消及正常收尾均恢复镜头、移动和交互。

## 验收标准

- F6 自动启动，五句独白和一句顾客对白逐字显示；E / 空格 / Enter 手动推进。
- 独白后停顿两秒，播放完整门铃，再展示顾客入店并沿过道走到订单机前。
- 自动演出期间不能自由移动；点单结束后镜头跟随玩家，WASD 移动和 E 交互恢复。
- 点击试玩面板的“取消演出”或对白期间按 Esc，能够恢复控制且不记录本次剧情完成。
- 本次不验收制作、交付、错误配方或后续对白。
