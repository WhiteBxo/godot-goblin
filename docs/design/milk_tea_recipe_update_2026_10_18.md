## 新设计的明确规则

- 每杯必须有一个基底，最多三个槽位，辅料可重复；基底资格与普通配方使用资格分别判断。F09 可作为基底但禁止用于普通配方。
- 六项属性以基底值起算，仅将每份辅料中达到 3 的属性加到对应项上，最终不设上限；风味、质地、效果标签分别去重。
- 第一版使用确定性名称与基底后缀，爆品按基底、辅料种类和数量完整匹配；普通饮品暂定 20G。
- 本次新表所有原料可使用次数均为 5；示例按购买价除以 5 分摊单次成本。当前库存数量语义未因此改变。
- 饮品图鉴按配方识别并去重。Signature_Products 完整数据和 Drink_Encyclopedia 均未包含在本次独立 Excel 中。

这些是设计摘要，原文及内嵌表格见专项转录稿；不表示当前游戏已具备相应行为。

## 字段差异与待确认项

| 位置 | 差异 / 缺口 |
| --- | --- |
| 原料字段 | DOCX 使用 `Recipe_Ingredients` 等逻辑表名，新 Excel 只有「哥布林奶茶配方」一张表；字段实际为「可作为基底」「基底命名」「普通配方可用」「市场价格」「可使用次数」等，不应按文中的英文表名猜测工作表。 |
| 成本 | DOCX 字段介绍写「单份成本」，新表存的是「市场价格」和次数；示例按购入一份可用 5 次计算。不能直接把市场价格写入旧运行时单件标价。F09 市场价格空白，不能默认为免费。 |
| 酒品价格 | 旧 W02/W04 标价为 4G/60G，新 F05/F06 市场价格为 20G/100G；新旧购买单位及经济含义有差异，现有运行时暂保留。 |
| 空值与类型 | Excel 的 TRUE/FALSE 是文本；效果「空」、空单元格需在以后数据接入时明确解析方式。F09 空白价格原样保留。 |
| 普通原料资格 | F09 普通配方可用为 FALSE；新规则与剧情专用血液特调需区分入口，不能因具备基底资格就开放自由配方。 |
| 加工 | 蜜珀晶从旧表「切块」改为新表「研磨成粉、捣碎」；其他原料也有增补。V0.1 第一版不要求玩家手动选择加工，未在本次改加工逻辑。 |
| 爆品与图鉴 | 新表没有完整爆品及专属售价，也没有图鉴数据表；旧 P01–P10 仍为空壳，不据此生成玩法。 |
| 美术命名 | 来源「橘子果酱」与 C09「苹果果酱」不符，按橘子原名入库，暂不绑定苹果果酱。 |
| 美术缺口 | 苔痕青无图片；萤火伞、窟窟糖芋各有多个未标注用途的版本，全部保留，暂不自行指定主图。醒神菇使用明确命名的原图，其余版本保留。 |
