# 第一天与第二天的场景连接约定

本连接方式由用户于 2026-10-17 确认，后续场景制作必须沿用。

```text

  ↕ 店门
奶茶店外公共街道
  ├─ 深处方向 ↔ 第五阶段夜间潜入区域（左下唯一对外入口）
  │                ├─ 醉酒守卫原位置（第二天送奶茶时重访）
```

- 第五阶段只有一个对外接口：左下接公共街道，进入与撤离共用。
- 第五阶段概念图右下类似出口的缺口必须封闭，不设第二条逃生路线。
- 长老宅邸正门是内部接口；室内外同图时只需经过门口，无须切场景。
- 第二天商业街岔路位于第五阶段图外，在公共街道上预留。
- 第二天送奶茶回到醉酒守卫的同一地点；由后续剧情/玩法宿主切换访问状态，不要求重做投币、贿赂和放火教学。
