# 第一天与第二天的场景连接约定

## 2026-10-19 新地图接法

当前接法以用户提供的洞窟拓扑图及[两天对接约定](two_day_flow_integration_plan.md)为准：新洞窟为统一外景，奶茶店在南侧集市旁，赌场在西南，酒馆在中央居民区右下，长老居所在东北。去商业地点不穿过潜入关卡，第二天可重访醉酒守卫原位置。

根据用户于 2026-10-19 的最新要求，取消潜入区域单一出入口、右下缺口必须封闭及军营侧／灰路封闭的约定。长老区三段附加路障及其碰撞已移除，通行恢复为已保存地图的原生地形规则。

正式地图绑定在 `src/levels/rpg_maker/chapter_*.tscn`，外景宿主沿用 `src/core/settlement.tscn`，三个室内为 `tavern.tscn`、`casino.tscn`、`elder_house.tscn`。地图通行和目标预检已接入；后续业务／剧情的实际发布状态见对应模块记录，不因门可通过就标记两天已通关。

## 2026-10-17 原始分图约定

以下保留 2026-10-17 的分图参考；出入口数量与封路限制已按上述最新要求取消。

```text
奶茶店室内
  ↕ 店门
奶茶店外公共街道
  ├─ 深处方向 ↔ 第五阶段夜间潜入区域
  │                ├─ 醉酒守卫原位置（第二天送奶茶时重访）
  │                └─ 长老宅邸正门 ↔ 宅邸内部
  └─ 外围方向 ↔ 第二天商业街
                   ├─ 酒馆门口 ↔ 酒馆内部
                   └─ 赌场门口 ↔ 赌场内部
```

- 公共街道承担路线分流。去酒馆、赌场不需要穿过长老居所区域。
- 长老宅邸正门是内部接口；室内外同图时只需经过门口，无须切场景。
- 第二天商业街岔路位于第五阶段图外，在公共街道上预留。
- 第二天送奶茶回到醉酒守卫的同一地点；由后续剧情/玩法宿主切换访问状态，不要求重做投币、贿赂和放火教学。
- 本文确认空间拓扑，不代表全部跨场景切换与剧情解锁已经实现。当前用户手工修改中的公共街道不得被离线重建脚本覆盖。
