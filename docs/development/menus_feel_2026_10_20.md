# 菜单与过场手感打磨（2026-10-20）

上一轮做了 UI 层级与制作节拍，这一轮补“打开菜单 / 过场”里仍然硬切或静止的时刻。全部是展示层改动：不写任务、剧情、经济与存档事实。

## 改动

| 时刻 | 之前 | 现在 |
| --- | --- | --- |
| 换日 / 章节卡 | 整张卡一起淡入，标题、副标题、空白一起出现 | 卡本身仍是一次淡入；内部“第一天”先到，金色细线从中间抽出来，地名最后到。总时长不变，跳过或取消都会复位 |
| 打开地图 | 目标是静态菱形 + 一圈线 | 目标标记外圈呼吸（`sin` 0.4–0.75 透明度），打开瞬间玩家位置扩散一圈“你在这里” |
| 目标文案变化 | 直接换字 | 目标那一行轻落一次 |
| 手册翻页 | 切 tab 时正文瞬间替换 | 新页 0.12s 淡入 + 0.99 → 1 落定；只动 alpha 与 scale，不重排 |
| 酒馆购买 | 反馈文字直接出现 | 成功：反馈行落地、余额弹一下、金额 `-12G` 从余额升起后淡出；失败：反馈行回缩 |
| 对白选项 | 三个选项同时出现 | 逐条 0.03s 错开淡入；只有 alpha 变化，焦点与布局不动 |

`src/UI/components/ui_flourish.gd` 随之补了两个通用动作：

- `reveal(control, from)`：容器换了内容，新内容落定（手册页、任何就地换页）。
- `float_text(anchor, text, color)`：数字变化的那一下从锚点升起后淡出（酒馆余额，也可给任何“花掉 / 得到”用）。

两者与既有的 `settle` / `stamp` / `refuse` / `cups` 共用同一套约束：只动 `scale`、`rotation`、`modulate`，只看最近的非 Container 祖先做浮层，重复触发先杀上一段。

## 实现要点

- `title_card.gd`：`show_card()` 的根节点淡入淡出保持原样，`_play_content()` 另起一条并行 tween 在同一 0.4s 内驱动标题 alpha、横线 `scale.x`、副标题 alpha；`_reset()` 把三者复位，所以连续换日或中途跳过不会留下半张卡。
- `map_canvas.gd`：新增 `ping()` 与 `_process`，只在可见且有目标或脉冲时 `queue_redraw`；未打开地图时不处理，避免常驻重绘。`map_panel.gd` 在变为可见时 `ping()`，目标文案变化时 `settle()`。
- `dialogue_ui.gd`：`reveal_all()` 里只在“选项首次出现”时调用一次 `_reveal_choices()`，重复 `reveal_all()` 不会重新播放。

## 试玩

1. 触发一次换日或章节过场，看标题、金线、地名的先后。
2. 解锁地图后按 M，注意目标外圈的呼吸与脚下那圈“你在这里”。
3. 打开手册，用方向键/点击在“任务日志 ↔ 异闻录”之间来回切，看新页落下。
4. 进酒馆买一份原料，看余额弹动与 `-多少G` 浮字。
5. 任意一次有选项的对白，看三个选项是否一条条出现。
