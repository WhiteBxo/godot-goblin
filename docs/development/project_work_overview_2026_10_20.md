## 二、六天演进

### 10-10｜引擎起步（13）

Godot 项目初始化 → 洞穴墙面 demo 模块化拆场景 → 目录层重排（MainGame 根 / CanvasLayer）→ 写开发规范 → TileMap 可在编辑器里编辑、场景 UID 可保。此时没有任何玩法，目标是"让工程结构站得住"。

### 10-16｜从 demo 到可玩 MVP（43）

题材在这一天定型为"哥布林奶茶店"。产出密度最高的是表现与演出基座：

- 移动与视觉：八向平滑移动、跑动动画、带边界的跟随镜头、商店背景替换。
- 状态：全局 `GameState` + 快照（`snapshot`）+ 隔离测试。
- 剧情表现三件套：JSON 对话系统、数据驱动 `StoryDirector`、`ActorDirector` 演出控制，外加 2D 电影镜头导演（带边界）。
- 音频：场景音频管理器 + 剧情音频适配器 + Ogg 前奏/循环播放。
- 场景流转：独立转场模块、像素交互反馈组件、房间无缝揭示。
- 玩法雏形：奶茶制作 + 共享库存；扁平洞穴聚落初版。

### 10-17｜系统层铺满（59）

这天的关键词是"把玩法做成系统"：

- UI 基座：共享主题 token、统一 modal 外壳（手册 / 商店 / 制作台共用）、任务与见闻录合并成可解锁手册。
- 存档：检查点校验 + 备份恢复 + 通过标题与游玩恢复。
- 经营：营业场次、顾客到访排期（幂等）、钱包原子交易、库存交付给指定 NPC。
- 剧情编排：游戏内 authoring + 隔离预览 + 自然语言源稿工作流，剧情步骤可直接调业务服务。
- 第一天：潜行投掷组件、守卫响应、聚落地图 UI 与目标标记。
- 角色：手持物可视化（`HeldItemVisual`）、随身仓库（B 键）。

### 10-18｜RPG Maker 素材迁移 + 两日流程（55）

- 素材：RPG Maker 地图与角色素材整体迁入，走廊/门框/遮挡关系修正。
- 架构：地图接入章节宿主，房间场景改为"按能力契约托管"（`HOST_MAP_CONTRACT`）。
- 经济：奶茶定价账本、原子使用交易，货币统一为 `G`（怪金币降为任务道具）。
- 两日章节流程打通，玩家/NPC 比例适配 + 镜头与移速补偿。
- 修复密集：提前接单、卡单、关店死锁、投掷方向颠倒、存档恢复等一串可玩性缺陷。

### 10-19｜内容扩张 + 手感打磨（67）

- 内容：10 款招牌配方 + 自由配方 + 饮品图鉴、第二日节日装扮、辣味试饮、第一夜潜入重做。
- 手感：UI 层级与指针反馈、菜单与场景切换的"节拍"、金币改胶囊并飞入滚动、玩家身体按速度自我应答（`PlayerBodyFeel`）。
- 美术：诗人/哲人/军人/三摊贩/胖哥布林的像素小人与立绘接入、胖哥布林三套坐姿情绪。
- 性能：HUD 按需重绘、门口目标场景预加载、潜入 HUD 降频、物理帧不再遍历出口。
- 存档：独立存档槽位 + 检查点恢复加固。

## 三、几条贯穿始终的主线

1. **形态演进**：洞穴 demo → 奶茶店 MVP → 扁平聚落 → RPG Maker 制式两日章节 → 可分发的两日试玩 demo。六天内完成了一次完整的"原型到交付"。
2. **表现层持续加码**：几乎每个阶段都有一批"节拍/手感"提交——转场、指针反馈、金币飞行、玩家体感、场景音乐淡入。这类提交在 10-19/10-20 占比明显上升，说明重心从"能不能玩"转向"玩起来像不像"。

4. **验证纪律**：117 个验证脚本 + 单一回归入口 + 退出码契约，属于"先建护栏再加快"的做法；`fix 70` 中有相当比例是回归测试先红、再修。
5. **敢于推翻**：夜间潜入被移除后按已确认场景重建、手持杯表现被否整体回退（`67ff0716`）、章节小地图与目标箭头被移除。返工集中在"表现方案"而非"系统架构"，说明系统层估得准、表现层靠试。
