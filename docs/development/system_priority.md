## 下一步验证

1. **人工完整步行与听感验收。** 从 F5 标题走完两天，观察商业与潜入路线、交互焦点、提示和音频。图形自动化 272 项已通过，但旅行靠近使用自动定位、对白自动推进，不能替代完整人工试玩。
2. **同步旧 UI 与 Demo 回归。** `verify_day1_stages_01_02.gd` 仍在旧 E 键焦点检查中止，后续旧 10G／实体币断言也需要按现行规则迁移；`verify_story_authoring.py` 仍被历史 Cinematic 顾客路线阻断。已用正式两天流程和室内真实交互检查覆盖当前发布内容，未把旧测试标为通过。
3. **当前提交的 Release 包验收。** 本轮未重新导出 Release；此前存档导出测试只证明其历史提交，不能作为当前版本的导出结果。

## 后续功能与需要的输入

| 优先顺序 | 范围 | 开始前的输入 |
| --- | --- | --- |
| 1 | 已发布内容的试玩问题 | 以实际阻塞、显示、操作与存档问题为准，局部修复并执行直接受影响检查 |
| 2 | 正式爆品内容 | 需要批准的配方与名称；150G 首次制作奖励机制已就绪，正式表为空，不发布测试夹具配方 |
| 3 | 独立战斗采购与四杯三槽装配 | 商品 ID、战斗等级／效果映射、购买流程与更换／退款规则；经营等级与战斗等级分别配置 |
| 4 | 第三天后续主线与长期经营 | 新源稿、明确日程／失败边界、正式宿主和恢复节点；本轮第三天交接不代表后续剧情已发布 |

放火、专用异常动画、自由赌博、长期雇佣、队伍、军队经营与完整战斗不在当前两天闭环范围。原料等级、Day 1 零钱／血液用量、Day 2 专款归属与购酒预算已经确定，不再作为阻塞项。
