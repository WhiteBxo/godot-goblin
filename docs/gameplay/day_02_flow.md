# 第二天完整流程与试玩

> 最新购菇流程：第二天到市场附近打开游戏菜单，胖子当场把 35G 交到钱包里，自己跑腿花 30G 货款、余下 5G 算跑腿费，也可在营业时临时委托散客，当晚带回。真实购买触发新增共享对白与 S06 配方发现；自己掏钱则走到摊主面前按 E，摊主先摆出货物，点中某件才开口介绍，再按报价结算。摊主只在第二天起搭理主角，第一天既不能对话也不能购买；醒神菇也不能自己采，只能买或雇人。免费采集和第三天购菇不补发配方。救治在第二、三天均可做，只扣一次用量，与配方资格分开。金额、存档与验证见[本轮记录](../development/story_supplement_2026_10_20.md)。

核对日期：2026-10-20，Godot 4.7.2。正式入口为 F5 → 新游戏，或标题页“继续游戏”。第一晚章末结束后自动进入第二天早晨；已处于第二天安全检查点的存档可以直接继续。

第二天已接通五阶段主线目标、柜台交付与配方键盘操作；最新[流程优化 A–C](../development/flow_optimization_abc_2026_10_19.md)将酒馆 / 赌场改为到对象前按 E 主动推进，增加顺路采集反馈和同款缺口批量制作。完整整合背景见[两天整合记录](../development/two_day_integration_2026_10_19.md)。

前两天体验补完见[最新实施记录](../development/two_day_experience_completion_2026_10_19.md)：支线 HUD 默认摘要、可选辛辣奶茶试饮、第二天祭典布置、守卫交付后的可选返店、赌场赌约／结果展示、章末回顾，以及标题／暂停中的基础设置。

## 玩家步骤

左上角主线卡随真实进度更新。J 打开任务手册，M 查看聚落地图；已配置地点的当前主线会在地图上标出目标圈，例如酒馆、赌场、奶茶店与长老居所支路。对白使用 E / Enter / 空格推进，按住确认键约 0.35 秒连续快进；设置里可开“对白自动播放”。剧情对白中 Esc 跳过本段剩余台词（遇选项停下），不会取消剧情事件。弹窗用 Esc 关闭。关店与雇佣在右上角菜单中操作，酒馆 / 赌场操作在世界中的吧台 / 赌桌进行。

| 阶段 | 操作 | 可观察结果 |
| --- | --- | --- |
| 早晨委托 | 听取胖哥布林的代购委托 | 35G 当场进钱包，`day2.procurement` 只记账；主线切到白天营业 |
| 白天营业 | 收银台按 E 接单，制作台按单制作，携杯回柜台按 E 交付；依次接待七日祭、长老、使者、传闻四组客人 | 前三组各一杯 H01，最后一组两杯，分别交给指定顾客；制作不自动交付 |
| 手动关店 | 可先点击雇佣散客代购；完成全部剧情订单并交清已接散客订单后，打开右上角菜单，点击“关店 · 前往酒馆” | 进入夜晚，目标提示前往酒馆；接待五杯本身不会自动关店 |
| 酒馆购酒 | 进门后先行走观察，向北到吧台前按 E 与裂牙交谈；再次按 E 购买，购酒后再按 E 听委托 | 标价 100G，八折实付 80G，获得一份琥珀酒（五次用量）；七日祭委托承认已采材料并显示持有量与缺口 |
| 两局赌场 | 到西南赌场，靠近入口上方最近的赌桌按 E 听规则，再分别按 E 确认两局 | 第一局产生十杯债务，第二局取得材料并免除债务；结果在同一赌桌附近揭示 |
| 守卫特调 | 离开赌场返回店里，制作台按 E 直接停在“自由实验”，自行选出植脂末奶茶底、格里芬琥珀酒、幻金菇，制作一杯 | 守卫特调不出现在“已知配方”；三样齐全即按委托特调入库，不需要单独报价 |
| 送达与返店 | 带杯出店，到长老居所支路的醉酒守卫处按 E 交谈，结束后再按 E 交付，最后实际返回奶茶店 | 招待不收钱；章末独白后进入第三天早晨 `day3.handoff` |

柜台优先选择可交付顾客，其次为收银台；没有订单的陪同者不再挡住接单。此规则仅用于柜台同组目标，面向制作台仍选择制作台。

夜晚三处材料点有对应的覆苔岩块、材料袋和菌丛，采后物件与标记一起消失。七日祭接取后显示当前持有份数和缺口；消耗共享库存会重新增加缺口，第三天仍在酒馆柜台前按 E 交付，奖励 60G。第二天最后两人组可先接齐同款订单，再一次确认制作当前缺口，交付仍逐人进行；第一天五位哥布林按新反馈逐位接待。

制作台提供“订单制作／已知配方／自由实验”三个直接入口。没有已接固定饮品订单时，制作台默认打开“已知配方”；守卫特调等待制作时改开“自由实验”，因为该特调只按手调的原料组合成立，不出现在已知配方列表里。仍有其他固定饮品订单时，也可直接切换“已知配方”。可选试饮需要在“自由实验”中自行选料、确认报价和制作。列表用鼠标或方向键选择，Tab 移到按钮、Enter 确认；内容较长时滚动查看，焦点移到确认按钮会自动将它滚入可见区域。

制作特调不会跳过守卫交谈，也不会完成交付。交付后必须走回店门触发返店，不能仅靠等待推进日期。代购为可选委托，雇佣从这笔钱里出，第二天雇佣者当晚返回；第三天完整剧情仍未制作。

## 主线与存档

新增 `day2.main.morning / business / tavern / casino / guard` 五项任务，全部读取现有剧情、交付与旅行事实，没有新增推进剧情的伪造开关，也没有修改对白、经济数值或存档格式。

旧版第二天存档缺少这些任务的终态记录时，既有目录绑定机制会依据保存的完成事实补记；原有任务结果、金钱、库存、回执和剧情阶段保持一致，单纯继续游戏不重写检查点文件。新版生成的存档按完整快照精确恢复验证。

## 官方 API 依据

本次核对 [Godot 4.7 TabContainer.current_tab](https://docs.godotengine.org/en/4.7/classes/class_tabcontainer.html#class-tabcontainer-property-current-tab)：容器根据当前页管理子控件可见性，默认页通过容器 API 切换，避免手动显示子页与容器选择冲突。已知配方沿用原生控件输入，模态取消、焦点和玩家输入锁继续交给 UIManager。
