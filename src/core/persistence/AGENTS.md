# 检查点与文件存档

- GameState 是唯一整局事实来源；SaveStore 只做完整快照文件读写，不创建另一份可写会话或 autoload。
- SaveCheckpoints 从配置解析可恢复阶段。新阶段必须同时提供场景恢复配置与跨进程验证；未知阶段不自动保存。
- SaveCoordinator 在主线程安全边界合并保存，不从同步 state_changed 回调写文件，不保存潜入尝试中间态。
- 读取必须先校验快照、检查点及资源，再整体恢复。落点恢复不是实际出入口旅行，不能写抵达事实。
- 正式档和备份只在临时文件回读验证后替换；损坏文件不覆盖有效备份。测试使用独立目录，不读写玩家正式档。

接口与验收见 [存档系统](../../../docs/systems/save_system.md)，验证按 [tests 规范](../../../tests/AGENTS.md)。
