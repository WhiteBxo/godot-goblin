# Shader 与遮挡材质

本目录保存 Shader 与配套配置。修改前核对当前项目的渲染器、材质实例和实际消费者；Godot API 按根规范查对应版本官方文档。

- 遮挡裁片与玩家 cutout 的显示效果不承担碰撞、移动、交互或剧情逻辑；房间职责见 [rooms/AGENTS.md](../gameplay/rooms/AGENTS.md)。
- 修改 uniform 的名称、类型或坐标约定时同步直接设置它的脚本 / 材质；明确使用纹理、本地、世界还是屏幕坐标，不散落重复换算。
- 谨慎处理共享 ShaderMaterial 的实例关系，不因一个角色或房间的参数调整影响其他实例；保持原素材比例和既有遮挡层级。
- 视觉验收使用直接受影响场景观察透明边缘、缩放与前后遮挡；只有影响逻辑或公共参数契约时才按 [验证分级](../../tests/AGENTS.md) 扩大检查，不为纯视觉微调默认回归整个项目。
