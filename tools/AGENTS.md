# 离线工具与生成流程

本目录保存命令行工具、素材处理、显式导入和编排校验，不承担游戏运行时逻辑。

- 工具按 `art/`、`audio/`、`characters/`、`map/`、`story/` 等现有功能归类，不为一次任务整理无关工具或移动旧脚本。
- 明确输入、输出、单位与工作目录，记录可复现命令；生成结果写到任务对应目录，源文件与派生文件分开，不覆盖用户原图或手工布局。
- 地图 JSON 导入必须显式指定输出并核对影响，通常先生成新场景检查；不能把离线导入自动挂到游戏启动或用旧 JSON 重建保存的 TileMap。相关规则见 [关卡规范](../src/levels/AGENTS.md)。
- 图片 / 音频处理读 [素材规范](../assets/AGENTS.md)，地图处理加读 [地图素材规范](../assets/map/AGENTS.md)。沿用现有处理链，不额外生成无关变体或提交缓存。
- `story/validate_story.gd` 与编排工具遵守 [剧情源稿规范](../docs/design/AGENTS.md) 和 [清单规范](../docs/story_authoring/AGENTS.md)；源码与严格 Loader 决定可接受 Schema，不由工具悄悄扩展运行时格式。
- 修改生成文件的路径或格式时同步直接消费者、文档目标与导出规则；例如音效映射随生成工具更新，不只手工修生成结果。
- 工具验证只选择本次输入和输出，检查可解析、可复现及关键引用；是否执行模块测试按 [验证分级](../tests/AGENTS.md) 决定，文档中的候选命令不自动全部运行。
